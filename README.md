# Aegis Cybersecurity Platform

A premium, futuristic cybersecurity SaaS platform designed for the digital frontier. Aegis combines high-end minimalist luxury with state-of-the-art interactive elements to provide a cinematic user experience.

## ✨ Features

- **Interactive Global Intelligence Grid**: A 3D Three.js visualization of real-time threat intelligence.
- **Cinematic Deployment Flow**: Immersive full-page animation sequence for system initialization.
- **Micro-interactions**: Smooth transitions and hover effects powered by Framer Motion.
- **Operational Dashboard**: Real-time status monitoring and defense matrix analytics.
- **Enterprise-Grade Aesthetics**: Sleek dark mode design with glassmorphism and neon accents.

## 🚀 Tech Stack

- **Frontend**: 
  - React 18
  - Tailwind CSS (Utility-first styling)
  - Framer Motion (Animations)
  - Three.js (3D Graphics)
- **Backend**:
  - Python / Flask
  - Gunicorn (Production WSGI server)
- **Design**:
  - Custom Cyberpunk Aesthetic
  - Glassmorphic UI Components

## 🛠️ Local Development

1. **Clone the repository**:
   ```bash
   git clone <your-repo-url>
   cd "Cyber security app development website"
   ```

2. **Set up the backend**:
   ```bash
   # Create a virtual environment (optional but recommended)
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate

   # Install requirements
   pip install -r requirements.txt
   ```

3. **Run the server**:
   ```bash
   python app.py
   ```
   The application will be available at `http://localhost:5000`.
